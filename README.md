# Lead Connect Clone

Hotel operations application (development in progress).

## Current contents

- `apps/api`: Node.js / Express / TypeScript API with Prisma schema and authentication foundation.

## Status

Source scaffold only. This has not been deployed or verified for production use. Do not store real guest or employee data until security and integration testing are completed.

## Project files

Project management files and backups are kept in the existing Google Drive `Lead Connect Clone` folder. Google Drive is not a live database or an automatic GitHub sync.

## Local setup

See `apps/api/README.md` for API setup and environment variable instructions. Never commit `.env` or credentials.
